Method手法

  1. The problem is "object detection". Not "is there a cavity in this x-ray?" but "where are the problems, and which kind is each?" The answer is a set of boxes with names.
  2. The model is Faster R-CNN. A well-known box-finding model built from CNNs. It proposes candidate boxes, then judges each one. It is a program; what makes it useful are its millions of learned numbers ("weights").
  3. We don't start from zero: fine-tuning. torchvision gives us Faster R-CNN with weights already learned on COCO, 330,000 everyday photos. It can already find things. We replace only its last part and teach it our 4 kinds of tooth problem.
  4. Learning = supervised, by repetition. DENTEX gives 705 x-rays with dentists' boxes as the answer key. The model guesses, the loss measures how wrong it was, the weights get nudged. One pass over all 705 is an epoch; we do 10.
  5. Measuring = mAP on x-rays it never saw. 50 x-rays are kept hidden. After each epoch we score the model on them with mAP, the standard box-finding score. The best epoch wins.
  1. 問題は「物体検出」。「このX線に虫歯はあるか？」ではなく「問題はどこにあり、どの種類か？」。答えは名前付きの四角の集まり。
  2. モデルは Faster R-CNN。 CNN を組み合わせた有名な四角当てモデル。候補の四角を出し、1 つずつ判定する。モデル自体はプログラムで、役に立つのは学習で決まった何百万個もの数（「重み」）。
  3. ゼロからは始めない：ファインチューニング。 torchvision には、日常写真 33 万枚（COCO）で学習済みの重み付き Faster R-CNN が入っている。物を見つける力はもうある。最後の部分だけ取り替えて、歯の問題 4 種類を教える。
  4. 学習＝答え付きで、繰り返す（教師あり学習）。 DENTEX のX線 705 枚に歯科医の四角が付いていて、これが答え。モデルが当てる → 損失で間違いの量を測る → 重みを少し直す。705 枚を 1 周するのが 1 エポック。10 周した。
  5. 測る＝見たことのないX線で mAP。 50 枚は隠しておく。各エポックの後、その 50 枚で四角当ての標準スコア mAP を出す。一番良かったエポックを採用。

Terms用語

CNNConvolutional Neural Network The basic building block of image AI. Slides a small window over the picture to find edges, then shapes, then textures. Stacks of these layers make a "neural network". 画像 AI の基本部品。小さな窓を写真の上でずらしながら、輪郭 → 形 → 模様の順に見つける。この層を何十段も重ねたものが「ニューラルネットワーク」。
R-CNNRegion-based CNN A way to find where things are, not just what is in the picture: first propose candidate regions (boxes), then run a CNN on each region to say what it is. Faster R-CNN (2015) is the fast version where the proposals are also made by a network. This project uses it. 写真に「何が」あるかだけでなく「どこに」あるかを見つける方式。まず候補の領域（四角）を出し、各領域を CNN で判定する。Faster R-CNN（2015 年）は候補出しもネットワークでやる高速版。このプロジェクトはこれを使う。
RPNRegion Proposal Network The small network inside Faster R-CNN that proposes the candidate boxes: "something might be here". Hundreds per picture. Faster R-CNN の中で候補の四角を出す小さなネットワーク。「ここに何かあるかも」を 1 枚あたり何百個も提案する。
ResNet-50 · FPNResidual Network, 50 layers · Feature Pyramid Network ResNet-50: the big 50-layer CNN that turns the x-ray into feature maps. FPN: combines its coarse and fine maps so both small cavities and large teeth show up. Step 2 of the model. ResNet-50：X線を特徴マップに変える 50 層の大きな CNN。FPN：その粗い地図と細かい地図を合わせ、小さな虫歯も大きな歯も見えるようにする。モデルの 2 段目。
PyTorch · torchvisionMeta's machine-learning library · its image add-on The software we write the project in. torchvision ships a ready-made Faster R-CNN and the pretrained weights, so we write ~200 lines, not 20,000. プロジェクトを書くためのソフト。torchvision には出来合いの Faster R-CNN と学習済みの重みが入っているので、書くのは 2 万行ではなく約 200 行。
COCOCommon Objects in Context 330,000 everyday photos (dogs, cars, cups) with boxes drawn by people. Our model was first taught on these. It already knows "how to find things"; we teach it "what a cavity looks like". 人が四角を描いた日常写真 33 万枚（犬・車・コップ）。モデルはまずこれで教えられている。「物の見つけ方」は知っているので、教えるのは「虫歯の見た目」だけ。
Fine-tuningalso: transfer learning転移学習とも Borrowing a model that was taught on COCO and teaching it a little more for our job. Much faster and needs far fewer pictures than starting from zero. COCO で教えたモデルを借りて、自分の仕事のために少し追加で教えること。ゼロから始めるよりずっと速く、写真も少なくて済む。
DENTEXDental Enumeration and Diagnosis on Panoramic X-rays (MICCAI 2023) The public set of 705 + 50 panoramic x-rays with dentists' boxes that we learn from. MICCAI is the main medical-imaging AI conference. 歯科医の四角が付いたパノラマX線 705 ＋ 50 枚の公開データ。MICCAI は医用画像 AI の主要な学会。
Epoch · Lossone pass · amount of error1 周 · 間違いの量 Epoch: one pass through all 705 learning x-rays. Loss: a single number for "how wrong was the model" on them. Learning = repeating epochs to make loss go down. エポック：学習用 705 枚を全部 1 回見ること。損失：その写真で「どれだけ間違えたか」の数。学習とは、エポックを繰り返して損失を下げること。
mAPmean Average Precision  (0 – 1) The standard score for box-finding. A box is "right" if it overlaps the dentist's box enough and names the right problem. The score rewards few false alarms and few misses, averaged over the 4 kinds. mAP@0.5 = overlap of at least half counts (easy rule). mAP@[.5:.95] = also demands precise box placement (strict rule).
Our 0.481 does not mean "48% correct". It is one number for "few false alarms AND few misses", averaged over the 4 kinds. 1.0 = found everything, no false alarms. For cavities the model finds about half and 7 of 10 boxes it draws are false alarms, so that kind scores 0.25 and pulls the average down. 四角当ての標準スコア。歯科医の四角と十分重なり、問題の名前も合っていれば「正解」。誤報が少なく、見逃しも少ないほど高い。4 種類で平均。mAP@0.5 ＝ 半分以上重なれば正解（ゆるい採点）。mAP@[.5:.95] ＝ 四角の位置の正確さも要求（厳しい採点）。
今回の 0.481 は「48% 正解」ではない。「誤報が少ない、かつ見逃しが少ない」を 1 つの数にしたもので、4 種類の平均。1.0 ＝ 全部見つけて誤報ゼロ。虫歯はモデルが半分しか見つけず、描いた四角の 7 割が誤報なので 0.25。これが平均を引き下げている。

Purpose目的

  • Learn the whole loop by hand: teach a model, then use it on a new picture.
  • モデルを教えて、新しい写真で使う。この一連の流れを自分の手でやってみる。
  • The job: draw a box around every tooth that has a problem and say which problem — cavity, deep cavity, root-tip infection, or stuck tooth.
  • 仕事：問題のある歯を四角で囲み、どの問題かを言う。虫歯、深い虫歯、根の先の病気、埋まった歯の 4 種類。
  • Keep it small: three short PyTorch programs — load the data, teach the model, run it on one x-ray.
  • 小さく作る：PyTorch のプログラム 3 本だけ。データを読む、モデルを教える、X線 1 枚で動かす。

Summaryまとめ

Method手法

  • Dentists' boxes are the answer key. The model guesses, checks the key, and fixes itself — thousands of times. (supervised learning)
  • We start from a model that already knows how to find everyday objects (COCO) and only swap its last part to say "cavity" instead of "dog". (fine-tuning)
  • 10 passes over the 705 x-rays (epochs), 4 pictures at a time, with the pictures randomly mirrored so it cannot just memorise them.
  • 歯科医の四角が答え合わせ用の正解。モデルは当てて、答えを見て、自分を直す。これを何千回も繰り返す。（教師あり学習）
  • 日常の物を見つけられるモデル（COCO）から始め、最後の部分だけ「犬」ではなく「虫歯」と言えるように取り替える。（ファインチューニング）
  • 705 枚を 10 周（エポック）、4 枚ずつ。丸暗記できないように写真をランダムに左右反転。

Results結果

  • Best after pass 5: mAP@0.5 = . Not "48% correct": it is a combined false-alarm and miss score, 1.0 = perfect. After pass 5 it memorises instead of learning. (overfitting)
  • Stuck teeth are easy: it finds 9 out of 10. Cavities are hard: it finds about half, and also flags many healthy teeth.
  • It often mixes up "cavity" and "deep cavity" — they look alike.
  • 5 周目が最高：mAP@0.5 = 。「48% 正解」ではなく、誤報と見逃しを合わせた点で 1.0 が満点。5 周目以降は学ぶのではなく丸暗記し始める。（過学習）
  • 埋まった歯は簡単：10 本中 9 本見つける。虫歯は難しい：半分くらいしか見つけず、健康な歯にも印を付ける。
  • 「虫歯」と「深い虫歯」をよく取り違える。見た目が似ている。

Modelモデル

Faster R-CNN, as shipped by torchvision. Two stages: propose boxes, then judge each box. Below: each stage, the technology it is, and whether it was learned.

torchvision 版の Faster R-CNN。2 段階：四角の候補を出す → 1 つずつ判定する。各段階と、その技術名と、学習したかどうか。

COCO weights, adjusted during our trainingCOCO の重み、今回の学習で微調整 new, trained from scratch here新規、今回ゼロから学習 fixed procedure, nothing to learn固定の処理、学習なし
1. X-ray in1. X線を入れるtorchvision transformshrink to 1333 px wide, normalise brightness. (During training only: random left-right flip, done before this step — data augmentation, not part of the model.)幅 1333 px に縮小、明るさを正規化。（学習時だけ、この前にランダム左右反転＝データ拡張。モデルの一部ではない。）
→
2. Feature maps2. 特徴マップResNet-50 + FPNResNet-50: a 50-layer CNN that turns the picture into maps of edges, shapes, textures. FPN: combines its coarse and fine maps so small cavities and large teeth are both visible.ResNet-50：50 層の CNN。写真を輪郭・形・模様の地図に変える。FPN：その粗い地図と細かい地図を合わせ、小さな虫歯も大きな歯も見えるようにする。
→
3. Candidate boxes3. 候補の四角RPN (Region Proposal Network)a small CNN that marks "something might be here", hundreds of boxes per x-ray.「ここに何かあるかも」を出す小さな CNN。1 枚あたり何百個。
→
4. Crop4. 切り出しRoIAligncut each candidate out of the feature maps and resize to the same 7×7 grid.各候補を特徴マップから切り出し、同じ 7×7 の格子にそろえる。
→
5. Classify + refine5. 判定＋位置補正Box head (FastRCNNPredictor)for each crop: which of the 4 problems, or nothing; and nudge the box. The COCO version answered "dog / car / …"; we replaced it with a fresh one for our 4 classes.切り出しごとに、4 種類のどれか／何もない、を決めて四角を微調整。COCO 版は「犬／車／…」と答える部品だったので、4 種類用の新品に取り替えた。
→
6. Remove duplicates6. 重複を消すNMS (non-maximum suppression)several boxes on one tooth → keep the most confident, drop the rest. Then keep only boxes with confidence ≥ 0.5.同じ歯に四角が何個も → 一番自信のあるものだけ残す。最後に自信 0.5 以上だけ採用。
  • Training touches 2, 3 and 5. Everything in 2 and 3 starts from COCO and shifts a little; 5 starts random. Steps 1, 4, 6 have no learned numbers.
  • 学習で動くのは 2・3・5。2 と 3 は COCO の値から少しずれる。5 は乱数から始める。1・4・6 には学習する数がない。
  • Four error signals drive the learning: "is there something here" and "where exactly" from step 3; "which kind" and "where exactly" from step 5. Their sum is the loss curve in Results.
  • 学習を動かす誤差は 4 つ：3 から「何かあるか」「正確にどこか」、5 から「どの種類か」「正確にどこか」。その合計が結果セクションの損失曲線。

Dataデータ

Training boxes per class学習用の四角の数（種類別）

  • DENTEX: a public set of panoramic x-rays where dentists drew a box around each problem tooth and named the problem.
  • DENTEX：歯科医が問題の歯を四角で囲んで名前を付けた、公開のパノラマX線集。
  • 705 x-rays to learn from, 50 kept aside to test. 3529 boxes in total.
  • 学習用 705 枚、テスト用に別にしておいた 50 枚。四角は全部で 3529 個。

  • 偏りがある：虫歯が全体の 62%、根の先の病気は 4% だけ。少ない種類ほど覚えにくい。
