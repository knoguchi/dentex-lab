Teaching a computer to spot cavities on dental x-rays

コンピュータに歯のX線写真から虫歯を見つけさせる

We take a pretrained picture-finding model, show it 705 x-rays that dentists already marked up, and then test it on 50 new x-rays it has never seen.

学習済みの「写真から物を見つけるモデル」に、歯科医が印を付けたX線写真 705 枚を見せて覚えさせる。そのあと、見たことのない 50 枚でテストする。

01

Purpose目的

  • Learn the whole loop by hand: teach a model, then use it on a new picture.
  • モデルを教えて、新しい写真で使う。この一連の流れを自分の手でやってみる。
  • The job: draw a box around every tooth that has a problem and say which problem — cavity, deep cavity, root-tip infection, or stuck tooth.
  • 仕事：問題のある歯を四角で囲み、どの問題かを言う。虫歯、深い虫歯、根の先の病気、埋まった歯の 4 種類。
  • Keep it small: three short programs — load the data, teach the model, run it on one x-ray.
  • 小さく作る：プログラムは 3 本だけ。データを読む、モデルを教える、X線 1 枚で動かす。
02

How we did it & what happenedやり方と結果

Howやり方

  • Dentists' boxes are the answer key. The model guesses, checks the key, and fixes itself — thousands of times. (supervised learning)
  • We start from a model that already knows how to find everyday objects (COCO) and only swap its last part to say "cavity" instead of "dog". (fine-tuning)
  • 10 passes over the 705 x-rays (epochs), 4 pictures at a time, with the pictures randomly mirrored so it cannot just memorise them.
  • 歯科医の四角が答え合わせ用の正解。モデルは当てて、答えを見て、自分を直す。これを何千回も繰り返す。（教師あり学習）
  • 日常の物を見つけられるモデル（COCO）から始め、最後の部分だけ「犬」ではなく「虫歯」と言えるように取り替える。（ファインチューニング）
  • 705 枚を 10 周（エポック）、4 枚ずつ。丸暗記できないように写真をランダムに左右反転。

What happened結果

  • Best after pass 5: score out of 1 on the easy rule. After that it starts memorising instead of learning. (overfitting)
  • Stuck teeth are easy: it finds 9 out of 10. Cavities are hard: it finds about half, and also flags many healthy teeth.
  • It often mixes up "cavity" and "deep cavity" — they look alike.
  • 5 周目が最高：ゆるい採点で 1 点満点中 。それ以降は学ぶのではなく丸暗記し始める。（過学習）
  • 埋まった歯は簡単：10 本中 9 本見つける。虫歯は難しい：半分くらいしか見つけず、健康な歯にも印を付ける。
  • 「虫歯」と「深い虫歯」をよく取り違える。見た目が似ている。

Inside the modelモデルの中身

The model works in two steps: first "something might be here", then "what is it?". Everything except the last box was already trained on everyday photos; we only teach the last box. (Faster R-CNN)

モデルは 2 段階で動く。まず「ここに何かありそう」、次に「それは何か」。最後の箱以外は日常写真で学習済みで、教えるのは最後の箱だけ。（Faster R-CNN）

04

The x-rays使ったX線写真

How many boxes of each kind the model learned from学習に使った四角の数（種類別）

  • DENTEX: a public set of panoramic x-rays where dentists drew a box around each problem tooth and named the problem.
  • DENTEX：歯科医が問題の歯を四角で囲んで名前を付けた、公開のパノラマX線集。
  • 705 x-rays to learn from, 50 kept aside to test. 3529 boxes in total.
  • 学習用 705 枚、テスト用に別にしておいた 50 枚。四角は全部で 3529 個。
  • Lopsided: cavities are 62% of all boxes; root-tip infections only 4%. Rare kinds are harder to learn.
  • 偏りがある：虫歯が全体の 62%、根の先の病気は 4% だけ。少ない種類ほど覚えにくい。

      Results, in detail結果の詳細

      Mistakes while learning (学習中の間違いの量（loss損失) — lower is better）— 低いほど良い

      Score on the 50 test x-rays — higher is betterテスト用 50 枚でのスコア — 高いほど良い

      • Left: every pass, the model makes fewer mistakes on the x-rays it learns from. That never stops going down.
      • 左：周回ごとに、学習用の写真での間違いは減り続ける。止まらない。
      • Right: but on new x-rays, the score stops improving after pass 5. The model is starting to memorise the 705 pictures instead of learning what a cavity looks like. (overfitting)
      • 右：でも新しい写真でのスコアは 5 周目で頭打ち。虫歯の見た目を学ぶのではなく、705 枚を丸暗記し始めている。（過学習）
      • We keep the model from pass 5.
      • なので 5 周目のモデルを採用。

      Which kinds does it get right?どの種類を正しく当てたか

      Rows: what the dentists said. Columns: what the model said. The diagonal is correct. The "nothing" row = model drew a box where there was no problem. The "nothing" column = model missed a real problem. (confusion matrix)

      行：歯科医の答え。列：モデルの答え。対角線が正解。「なし」の行＝問題がない所にモデルが四角を描いた。「なし」の列＝本当の問題をモデルが見逃した。（混同行列）
